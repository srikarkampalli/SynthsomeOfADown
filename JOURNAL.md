# October 26th: literally starting out

Alright, so it's time to start a Hack Club project that I will truly feel passionate about and fully complete within the span of a week. I think Halloween is also going to come up in around that timeframe, so I can make something work out.
Anyways, I need to create my bill of materials and organize what I have. I was thinking of a Attiny85, a DFPlayer Mini, and an audio jack.

The DFPlayer Mini is a simple through-hole module. Simply create a few connections between its pins and the audio jack, and I should be set for the project!

I was also thinking of creating a case in Fusion 360. The good thing is that I can learn from this, since I am completely new to it. The bad thing is that it can be a pain to learn, and I will waste a lot of time on it.
